COVEFRAME 0.6.0 - WINDOWS PREVIEW

1. Extract the whole ZIP and open Coveframe.exe.
2. Follow the local wizard to create your household and connect accounts.
3. Recommended: TorBox Essential + Real-Debrid Premium. Choose TorBox Pro for Usenet.
4. Basic posters need no API key. Add optional personal ratings keys later.
5. Find titles adds streaming links. Optional downloads are in Settings.

CUSTOMIZE: Settings saves Moonfin/AIOStreams preferences. Reload Moonfin after saving.
STOP: Stop all apps keeps the dashboard open. Quit Coveframe also closes the wizard.
UNINSTALL: About this PC > Review uninstall. Removes apps, profiles, keys and settings;
media is kept. Then close the tab and delete this extracted folder.

DATA: %LOCALAPPDATA%\MediaHub\Setup. About this PC shows exact folders and ports.
Saved keys use Windows protection; vendor configuration/logs can contain credentials.
Never share your data directory. Closing the browser alone does not stop apps.
No VM, Docker, administrator rights, Windows service or separate Node install is needed.
Nothing starts automatically when Windows starts. Apps listen on this PC only.

This is an unsigned preview. Follow normal Windows trust decisions. Do not disable
antivirus or bypass Windows protection. Read RELEASE-NOTES.md for testing limitations.
Real-account playback/downloads, TV/LAN and software updates need further work.
Boot testing is deferred. Existing media installations are not changed.
