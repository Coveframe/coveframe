# Report a security issue

Use GitHub's private vulnerability reporting for this repository when available. Do not post API keys, account files, vendor databases, raw logs or playback URLs in a public issue.

For ordinary bugs, include your Coveframe version, Windows version, the action you tried and the message shown in the wizard. Redact private folder names if you include a screenshot. Never attach the app data directory.

This is an unsigned preview. Run it only for your own Windows user, keep it on loopback and do not expose its ports through a router or reverse proxy. Future verified releases will be listed on this repository's Releases page. No maintainer should ask you to disable Windows protection or send a provider key.
